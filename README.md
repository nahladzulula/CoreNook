# CoreNook

CoreNook is a high-performance, real-time system manager that enables auto-scaling and load-balancing for distributed server clusters.

With CoreNook, you get a lightweight tool that stays out of your way.

**What you get**

- CoreNook is a high-performance, real-time
- system manager that enables auto-scaling
- and load-balancing for distributed server

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/CoreNook.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure CoreNook, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
